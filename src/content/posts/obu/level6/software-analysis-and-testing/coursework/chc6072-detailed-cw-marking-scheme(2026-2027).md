<center><h2>CHC6072 Software Analysis and Test</h2></center>  
<center><h1>Detailed Coursework Marking Scheme</h1></center>  

The coursework is marked out of **100 marks**. It counts for **70%** of total assessment of the module.

| **Task/Aspects of Quality**                                                                                                                                                                                                                                                                               | **Mark Range** |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| **Task 1: Developing a test plan (25 marks)**                                                                                                                                                                                                                                                             |                |
| _1.1. The hyperlink graph model (10 marks)_                                                                                                                                                                                                                                                               |                |
| The hyperlink graph is correct and complete                                                                                                                                                                                                                                                               | 8-10           |
| The hyperlink graph is well structured and fairly complete                                                                                                                                                                                                                                                | 4-7            |
| The hyperlink graph does not match the system’s structure and missing major functions                                                                                                                                                                                                                     | 0-3            |
| _1.2._ The narrative description of the user story (stories) _(5 marks)_                                                                                                                                                                                                                                  |                |
| The narrative description is clear and concise and in the correct format of JBehave.                                                                                                                                                                                                                      | 5              |
| The narrative description is mostly clear and concise, but not in the correct JBehave format.                                                                                                                                                                                                             | 3-4            |
| The function under test is not properly described.                                                                                                                                                                                                                                                        | 1-2            |
| The narrative description is completely missing.                                                                                                                                                                                                                                                          | 0              |
| _1.3. Description of the scenarios (10 marks)_                                                                                                                                                                                                                                                            |                |
| The set of scenarios covers the function’s different uses thoroughly. Each scenario is clearly and precisely written in JBehave syntax that can be easy used for manual testing and developing automated test scripts.                                                                                    | 8-10           |
| The set of scenarios covers most of the function’s different uses, but some important ones are missing. The scenarios are mostly well written in JBehave format.                                                                                                                                          | 6-7            |
| There are some scenarios described, but far from adequate to cover the function’s different uses. The scenarios are written in the JBehave format.                                                                                                                                                        | 4-5            |
| No scenario descriptions, or the descriptions are not in JBehave format.                                                                                                                                                                                                                                  | 0-3            |
| **Task 2: Developing automated test scripts (25 marks)**                                                                                                                                                                                                                                                  |                |
| _2.1. Quality of the test scripts (20 marks)_                                                                                                                                                                                                                                                             |                |
| Test scripts have all of the following three qualities:<br>1. checking the correctness of the web application thoroughly;<br>2. suitable for regression testing using advanced Selenese commands<br>3. using appropriate control flow structure to increase coverage of different uses of the function.   | 15-20          |
| Test scripts have at least two of the following features:<br>1. checking the correctness of the web application thoroughly<br>2. suitable for regression testing using advanced Selenese commands<br>3. using appropriate control flow structure to increase coverage of different uses of the function.  | 11-14          |
| Test scripts have at least one of the following features:<br>1. checking the correctness of the web application thoroughly,<br>2. suitable for regression testing using advanced Selenese commands<br>3. using appropriate control flow structure to increase coverage of different uses of the function. | 8-10           |
| Test scripts only contain simple commands like click, clickAndWait, etc., but are executable without error.                                                                                                                                                                                               | 5-7            |
| Test scripts are simple and many are not executable without error.                                                                                                                                                                                                                                        | 0-4            |
| _2.2. Group test scripts into test suite (5 marks)_                                                                                                                                                                                                                                                       |                |
| Test cases are grouped into test suites                                                                                                                                                                                                                                                                   | 5              |
| Test cases are not grouped into a test suite                                                                                                                                                                                                                                                              | 0              |
| **Task 3: Performing automated testing (30 marks)**                                                                                                                                                                                                                                                       |                |
| _3.1. Execute the test suites in Selenium IDE (15 marks)_                                                                                                                                                                                                                                                 |                |
| All test cases/suites are executed without error using Selenium IDE to test the application in Chrome web browser successfully with evidence shown in the log file.                                                                                                                                       | 12-15          |
| All test cases/suites are executed using Selenium IDE to test the application in Chrome web browser with evidence shown in the log file. There are no more than 3 errors in the test scripts.                                                                                                             | 7-11           |
| All test cases/suites are executed using Selenium IDE to test the application in Chrome web browser with evidence shown in the log file. There are more than 3 errors in the test scripts.                                                                                                                | 1-6            |
| No good evidence to demonstrate that the test scripts are executed.                                                                                                                                                                                                                                       | 0              |
| _3.2. Translate test scripts into Java Test Code (10 marks)_                                                                                                                                                                                                                                              |                |
| Test scripts are translated correctly into Java Test Code without syntax and semantics errors.                                                                                                                                                                                                            | 6-10           |
| Test scripts are translated into Java Test Code with no more than 3 syntax or semantics errors.                                                                                                                                                                                                           | 4-5            |
| Test scripts are translated into Java Test Code with more than 3 syntax or semantics errors.                                                                                                                                                                                                              | 1-3            |
| Test scripts are not translated into Java Test Code.                                                                                                                                                                                                                                                      | 0              |
| _3.3. Execute Java Test Code in IDEA/JUnit (5 marks)_                                                                                                                                                                                                                                                     |                |
| The Java test code is executed without any error using IDE and JUnit to test the application in Chrome web browser successfully with evidence shown in a screen snapshot file.                                                                                                                            | 4-5            |
| The Java test code is executed using IDE and JUnit to test the application in Chrome web browser. There are some errors in the test code, but the code managed to open Chrome web browser. The evidence is shown in a screen snapshot.                                                                    | 1-3            |
| It is failed to install Selenium WebDriver for Chrome and failed to execute the Java test code using IDE and JUnit to test the application in Chrome web browser.                                                                                                                                         | 0              |
| **Task 4: Measuring test adequacy (20 marks)**                                                                                                                                                                                                                                                            |                |
| _4.1. Measure node coverage (10 marks)_                                                                                                                                                                                                                                                                   |                |
| Matrix correctly represents nodes covered by each test case                                                                                                                                                                                                                                               | 5              |
| Correct calculation of node coverage                                                                                                                                                                                                                                                                      | 5              |
| _4.1. Measure hyperlink coverage (10 marks)_                                                                                                                                                                                                                                                              |                |
| Matrix correctly represents the hyperlinks covered by each test case                                                                                                                                                                                                                                      | 5              |
| Correct calculation of hyperlink coverage                                                                                                                                                                                                                                                                 | 5              |
